# App icon

Created with the built-in imagegen tool. `AppIcon.png` is the generated source;
`AppIcon.icns` contains the native macOS icon sizes, converted using `sips` and
`iconutil`. No external image library is needed to build or run the app.

## Generation prompt

Use case: logo-brand. Asset type: finished macOS application icon for Keychain Compatibility Layer, a small native utility connecting software keychain functionality. Create one polished 1024x1024 square icon: a rounded-square deep graphite and ocean-teal tile, with generous transparent outer margin and clean antialiased alpha edges. Center a single bold, elegantly interlocking silver key and teal chain-link emblem, the key's circular bow itself forming one of the two interlocked links; very legible silhouette at 32 pixels. Subtle machined-metal bevels and soft restrained dimensional lighting, contemporary premium macOS utility aesthetic, front-facing, balanced, minimal. No text, no letters, no Apple or OpenAI logos, no lock/shield cliché, no fake hardware chip, no watermark, no surrounding scene. Only one icon, not a presentation sheet. Truly transparent background outside the rounded square.
